# IndusLedger AI

An intelligent industrial monitoring and management platform designed to streamline operations, data ledger tracking, and automated insights.

---

## 🚀 Features

* **Real-time Industrial Monitoring:** Track key operational metrics and ledgers seamlessly.
* **Database Integration:** Powered by Supabase for backend services and data persistence.
* **Modern Stack:** Built using React, TypeScript, and Vite for optimal speed and reliability.
* **Secure Authentication:** Integrated user authentication and access controls.

---

## 🛠️ Tech Stack

* **Frontend:** React, TypeScript, Vite
* **Backend / Database:** Supabase
* **Styling:** Tailwind CSS

---

## 💻 Getting Started Locally

Follow these steps to set up and run IndusLedger AI on your local machine:

### Prerequisites
Make sure you have Node.js (v18 or higher) installed on your system.

### Installation

1. **Clone the repository:**

git clone https://github.com/iqraruddin127-khan/IndusLedger.git
cd IndusLedger

2. **Install dependencies:**

npm install

3. **Set up environment variables:**
   Create a `.env` file in the root directory and add your Supabase credentials:

VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key

4. **Run the development server:**

npm run dev

---

## 🔒 Security Notice

The `.env` file containing sensitive API keys and environment configurations is excluded from version control to ensure security. Make sure to keep your environment variables confidential.
